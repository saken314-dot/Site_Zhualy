# Сайт ТОО «ЖУАЛЫСТРОЙБИЗНЕС»

Одностраничный сайт строительной компании: `index.html` без сборки и зависимостей.

## Что заменить перед публикацией
Все места, выделенные жёлтой пунктирной рамкой (класс `todo` в `index.html`):
- цифры в шапке (год основания, число объектов, специалистов и техники);
- телефон, WhatsApp, e-mail, адрес, БИН;
- карточки объектов (названия и фото);
- номер WhatsApp в константе `WHATSAPP` внизу файла: туда приходят заявки из формы.

После замены уберите `class="todo"` у этих элементов.

## Публикация через GitHub Pages
Settings → Pages → Source: Deploy from a branch → `main` / `(root)`.
