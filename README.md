# Сайт ТОО «ЖУАЛЫСТРОЙБИЗНЕС»

Одностраничный сайт строительной компании: `index.html` + фото в `img/`, без сборки и зависимостей.

- Сайт: https://saken314-dot.github.io/Site_Zhualy/
- Будущий домен: zhualystroi.kz (DNS на ps.kz уже настроен; после активации домена вернуть файл `CNAME` с текстом `zhualystroi.kz` и включить Enforce HTTPS в Settings → Pages)

## Содержание сайта
Реквизиты, контакты, лицензия, стандарты ISO и опыт — в `index.html`.
Исходные документы (лицензия, сертификаты, список работ) в публичный репозиторий не загружаются.
